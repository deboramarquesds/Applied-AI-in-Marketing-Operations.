# Applied-AI-in-Marketing-Operations.
An AI-assisted workflow that uses dedicated client chats to create marketing content aligned with each brand’s voice and goals.

## AI-Assisted Content Creation

I developed this workflow for my day-to-day work at a marketing agency. I set up a dedicated AI chat for each client and add context about their brand, target audience, tone of voice, and past content. When a new request comes in, I provide the brief and use the chat to brainstorm ideas and draft social media captions and video scripts. I then review and edit the drafts to make sure they fit the brief and reflect the client’s voice.
